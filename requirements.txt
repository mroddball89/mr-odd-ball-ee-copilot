# Gestures — the camera pointer and the thumbs-up approval.
#
# **This block used to say "NOTHING IS LISTED HERE, AND THAT IS THE ENTRY", and it was right
# at the time.** On the Pi, mediapipe went into a SEPARATE Python 3.12 venv built by
# `tools/install_gesture_venv.sh`, and `tools/gesture_control.py` shelled out to it for one
# token per approval. The reason, measured on the Pi 2026-08-22:
#
#   mediapipe 1.0.1   on py3.13   installs cleanly, then SIGKILLs at XNNPACK delegate
#                                 creation. Every vision task. No OOM, 6.4 GB free.
#   mediapipe 0.10.18 on py3.12   works. Both its APIs work. 88 ms/frame.
#   mediapipe 0.10.20+            publishes no aarch64 wheel at all.
#
# The only mediapipe that ran there needed a <=3.12 interpreter and the Pi's main venv was
# 3.13.5, so a 400 MB sidecar was the right trade against moving 1.9 GB of working audio stack.
#
# **None of that applies here and the whole argument is void.** This workstation is Python
# 3.12.10, so mediapipe and opencv import in the main interpreter — verified 2026-08-26,
# `python tools/gesture_pointer.py --check` reports `detector tasks` with no sidecar at all.
# There is no aarch64 wheel question because there is no aarch64. `install_gesture_venv.sh` was
# deleted with the rest of the Pi tooling.
#
# So they are declared, like everything else. The model file pip does not carry is still
# needed, 7.8 MB, gitignored:
#     python tools/gesture_control.py --fetch-model

# =======================================================================================
# The face — his window on the desktop (hud/float.py). Added 2026-08-26.
#
# PyQt6-WebEngine and NOT pywebview, and the reason is one property rather than taste.
# `--transparent` is load-bearing: the solo look is the character composited onto the desktop
# with no rectangle seam, which needs the page transparent AND the window transparent
# together. pywebview on Windows drives WebView2, whose transparency is a
# `DefaultBackgroundColor` that does not reliably reach a layered top-level window. Qt does it
# directly — `WA_TranslucentBackground` plus `page().setBackgroundColor`.
#
# It is ~150 MB, which is the single largest thing in this file, and on the Pi that trade
# could never have been made. It is the first place the new hardware actually bought something.
#
# This replaces GTK4 + WebKitGTK, which was never a pip dependency at all — it was
# `sudo apt install gir1.2-gtk-4.0 gir1.2-webkit-6.0 libwebkitgtk-6.0-4 python3-gi`, because
# PyGObject is a system package on Debian and building it from source on the Pi is a fight
# nobody needs. On Windows there is no system package and no fight; it is a wheel.
# =======================================================================================
PyQt6>=6.7                           # the window, its flags, and the escape-hatch shortcuts
PyQt6-WebEngine>=6.7                 # the WebView that renders hud/face-preview.html
